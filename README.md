# 🚀 ENGLISH TYPING AUDITION (STATIC WEB EDITION)
### Lộ Trình Luyện Gõ Tiếng Anh Thực Chiến Band 4.0 ➔ 7.0 & 100 Từ Vựng IT

> **Phiên bản Static Web thuần túy (HTML5 / CSS3 / Vanilla JS)**: Không cần cài đặt Java hay Spring Boot, không cần server backend. Có thể mở trực tiếp trên trình duyệt hoặc deploy miễn phí 100% lên GitHub Pages, Vercel, Netlify để chia sẻ link cho bạn bè cùng luyện tập!

## 🌟 TÍNH NĂNG NỔI BẬT

1. **📖 Học Từ Mới Cốt Lõi**:
   - ⚡ Động từ bất quy tắc (V2/V3) hay nhầm lẫn.
   - 💻 **Bộ 100 từ vựng IT & Kỹ thuật phần mềm** (chia làm 4 nhóm: *Lập trình*, *Cloud & DevOps*, *Database*, *Bảo mật & AI*).
   - Ẩn hoàn toàn đáp án và chữ cái gợi ý, buộc người học truy xuất từ vựng từ trí nhớ.
2. **⚡ 67 Bài Tập 6 Thì Gài Bẫy**:
   - Phân bố qua 3 cấp độ (Band 4.0 - 5.0, Band 5.0 - 6.0, Band 6.0 - 7.0+).
   - Tích hợp **Cẩm nang 6 thì** tra cứu công thức, dấu hiệu và mẹo ghi nhớ.
3. **🎯 Collocations & Chunks**: Luyện gõ các cụm từ cố định tự nhiên của người bản xứ.
4. **✨ Sentence Upgrade 4.0 ➔ 7.0**: Nâng cấp từ câu đơn sang cấu trúc học thuật (Đảo ngữ, Mệnh đề quan hệ rút gọn, Câu chẻ).
5. **🎧 Dictation Speed Audition**: Luyện nghe bóc tách âm đuôi (/s/, /z/, /ed/) và hiện tượng nối âm theo 3 tốc độ (0.75x, 1.0x, 1.25x).
6. **📝 Academic Reading & Evidence**: Luyện đọc hiểu IELTS Paragraphs A-D và định vị dẫn chứng.
7. **📓 Sổ Tay Lỗi Sai (Mistake Vault)**: Tự động lưu các từ bạn gõ sai để ôn tập lại theo phương pháp lặp lại ngắt quãng (SRS).
8. **🎮 Cảm Giác Nhịp Điệu Audition**: Âm thanh gõ phím cơ học, tính điểm Combo, hiệu ứng Meme ăn mừng và khả năng upload nhạc nền BGM riêng.

## 🚀 HƯỚNG DẪN DEPLOY MIỄN PHÍ ĐỂ BẠN BÈ TRUY CẬP

### CÁCH 1: DEPLOY LÊN GITHUB PAGES (KHUYÊN DÙNG - 100% MIỄN PHÍ)

Thư mục đã có sẵn file cấu hình tự động `.github/workflows/deploy.yml`. Bạn chỉ cần làm theo 4 bước sau:

#### Bước 1: Tạo Repository mới trên GitHub
1. Đăng nhập vào [GitHub](https://github.com/).
2. Nhấn nút **New** (Tạo repo mới).
3. Đặt tên repo (ví dụ: `english-typing-web`), chọn **Public**, rồi bấm **Create repository**.

#### Bước 2: Đẩy source code lên GitHub
Mở **Terminal / PowerShell** tại thư mục này (`C:\Users\USER\IdeaProjects\english-typing-web`) và chạy các lệnh sau:

```bash
# 1. Khởi tạo Git
git init

# 2. Thêm tất cả file vào git
git add .

# 3. Tạo commit đầu tiên
git commit -m "Initial commit - English Typing Audition Static Web"

# 4. Đổi tên nhánh sang main
git branch -M main

# 5. Liên kết tới GitHub repo của bạn (thay username và tên repo của bạn)
git remote add origin https://github.com/<your-username>/english-typing-web.git

# 6. Push code lên
git push -u origin main
```

#### Bước 3: Kích hoạt GitHub Pages
1. Trên giao diện GitHub của Repo vừa tạo, vào tab **Settings** ➔ chọn mục **Pages** (ở cột bên trái).
2. Tại mục **Build and deployment** ➔ **Source**:
   - Chọn **GitHub Actions** (Workflow tự động deploy sẽ chạy ngay lập tức).
   - *Hoặc* chọn **Deploy from a branch** ➔ chọn branch `main` ➔ `/ (root)` ➔ bấm **Save**.

#### Bước 4: Nhận link web và gửi cho bạn bè! 🎉
Sau khoảng 1-2 phút, GitHub sẽ tạo cho bạn một đường link dạng:
👉 **`https://<your-username>.github.io/english-typing-web/`**

Bạn chỉ cần gửi link này cho bạn bè, mở trên máy tính hoặc điện thoại là dùng được ngay lập tức!

---

### CÁCH 2: DEPLOY LÊN VERCEL (SIÊU NHANH TRONG 30 GIÂY)

1. Truy cập [vercel.com](https://vercel.com/) và đăng nhập bằng GitHub.
2. Bấm **Add New...** ➔ **Project**.
3. Chọn repo `english-typing-web` từ GitHub của bạn.
4. Bấm **Deploy** (không cần cấu hình thêm gì).
5. Sau 15 giây, bạn sẽ nhận được link web cực nhanh dạng:
   👉 **`https://english-typing-web.vercel.app/`**

---

### CÁCH 3: DEPLOY LÊN NETLIFY (KÉO THẢ TRỰC TIẾP KHÔNG CẦN GIT)

1. Truy cập [app.netlify.com/drop](https://app.netlify.com/drop).
2. Kéo toàn bộ thư mục `english-typing-web` thả vào khung trình duyệt.
3. Netlify sẽ cấp ngay một đường link web công khai sử dụng vĩnh viễn!

## 💻 CHẠY THỬ NGHIỆM TRÊN MÁY CỦA BẠN (LOCAL)

### Cách đơn giản nhất:
Nhấp đúp chuột trực tiếp vào file `index.html` để mở trên Chrome, Edge hoặc Brave.

### Chạy bằng Local Web Server (nếu muốn test cổng localhost):
Nếu máy bạn có cài đặt Node.js:
```bash
npm start
# Hoặc
npx serve -l 3000 .
```
Truy cập: **http://localhost:3000**
